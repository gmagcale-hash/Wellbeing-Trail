Firebase Team Leaderboard & Shared Sync

Firebase setup: create a Firebase Web App, enable Anonymous Authentication, and create Cloud Firestore. Then paste the Web App configuration JSON below. The game uses Firestore for the shared leaderboard and profile photos, so you do not need Firebase Storage.
Firestore security rules 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /wellbeing_logs/{logId} {
      allow read, create: if request.auth != null;
      allow update, delete: if request.auth != null;
    }
    match /players/{userId} {
      allow read: if request.auth != null;
      allow create, update: if request.auth != null && request.auth.uid == userId;
    }
  }
}
Why no Firebase Storage?

Profile pictures are resized before saving and stored in each player's Firestore document. This keeps the setup on Firebase's no-cost Spark plan and avoids requiring a billing account for Cloud Storage.
